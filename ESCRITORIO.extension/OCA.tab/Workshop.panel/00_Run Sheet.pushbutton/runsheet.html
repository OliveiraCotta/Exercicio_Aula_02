From Model to Browser

Your step-by-step guide for the two days. Work along on your own machine; checkpoint files are there if you fall behind.

2 days · 4 h each Revit · Power Query · PA Academy plugin · dashboard
Revit model-> Power Query-> PA Academy plugin-> HTML dashboard Clean and merge the data, check the model, turn it into a shareable health scorecard, then open it straight from Revit.
Revit Excel · Power Query Plugin Browser Claude Watch

Before you start (have these ready)

  • Revit 2025+ and pyRevit installed. Day 1 you build the tower from a blank project - don't open the provided model (it's only a fallback if you fall behind). Day 2 you open the finished PA_Modular Tower.rvt, which already has the rooms and data in it.
  • We build the PA Academy plugin together on Day 2, so you only need pyRevit ready - your instructor shows how to create the extension folders.
  • Microsoft Excel (Power Query is built in) and a modern web browser.
  • The Day 1 and Day 2 data files your instructor shared.
  • Optional: a Claude account if you want to run the AI prompts yourself.

Tip: you can reopen this guide anytime from the Run Sheet button in the PA Academy tab.

1.4
Excel · Power Query
Open the Day 1 data file and meet Power Query
  • Open Day 1 ▸ D1_PA-Workshop_DATA.xlsx (tabs: Specifications, Quantities, Rates, Read me).
  • Click any cell in Specifications ▸ Data ▸ From Table/Range. The editor opens; watch the Applied Steps panel on the right.
  • The idea: you are not cleaning data once, you are building a cleaning machine you can reuse.
1.5
Excel · Power Query
Exercise 1: clean the specification into keynotes

Build it with clicks only, one step at a time. Each step fixes a real problem in the data:

  • Choose the columns you need, then filter Status (drop Superseded and On Hold) and Phase (keep CD, DD and blank).
  • Remove duplicates, then Trim and remove duplicates again - key 033000.01 has a trailing-space twin that only collapses after the Trim.
  • Add KeynoteText, then derive Parent_Key from the first two characters of the key (033000.01 -> 03).
  • Keep the three keynote columns, then Close & Load.
CheckpointD1_PA-Workshop_DATA_prebuilt.xlsx ▸ Keynotes_EN (50 keynotes).
1.6
Excel · Power QueryRevit
Export the Revit keynote file
  • Keep the three columns in order, delete the header row, then Save As ▸ Unicode Text (*.txt).
  • In Revit: Annotate ▸ Keynote ▸ Keynoting Settings and point to your .txt.
ProvidedKeynotes_EN.txt / Keynotes_FR.txt are ready to use.
1.7
Excel · Power Query
Exercise 2: build a costed bill of quantities
  • On the Quantities tab: Data ▸ From Table/Range.
  • Group By Keynote_Key + Type_Name + Unit; sum Quantity as Total Qty and add Count Rows as Levels. Grouping by Unit keeps m2, m and ea apart.
  • Merge Queries with your Keynotes_EN on Keynote_Key (Left Outer), expand the description.
  • Merge Queries again with the Rates tab on Keynote_Key, expand Unit_Rate.
  • Select Total Qty and Unit_Rate, then Add Column ▸ Standard ▸ Multiply for Line Cost.
CheckpointD1_PA-Workshop_DATA_prebuilt.xlsx ▸ BoQ_EN (27 items).

Notice: key 095113.09 is modeled but not in the spec, so its description stays blank - a real coordination flag.

1.8
Excel · Power Query
Try the one-click refresh

Change a value or drop in a new export, then click Data ▸ Refresh All. Every step runs again. Same query, next project. That is the payoff.

Day 2

Plugin, validation, and the dashboard

Install the plugin, check and fix the model, extend it with Claude, compare against the brief and open the dashboard - then a quick Revit MCP demo to close.
2.1
Plugin
Module 1 - Install the pyRevit plugin
  • pyRevit turns folders into buttons: PA Academy.tab ▸ Workshop.panel ▸ 01_Name.pushbutton, each holding a script.py + icon.png.
  • Drop the folder in %APPDATA%\pyRevit\Extensions, then Reload pyRevit - the PA Academy tab appears.
CheckpointThe finished PAACADEMY.extension is provided - copy it in and reload.
2.2
PluginExcel
Module 2 - QA/QC: check and fix the model
  • Look first: PA - Rooms QA (Department) and sheet PA-QA. White rooms = missing data. Guess the grade.
  • Element QA/QC ▸ Rooms checks Department + Occupancy; run it on Walls for Fire Rating too (it works on any category - see sheet PA-FR).
  • Export (.xlsx), fill the blanks (leave the RoomID/ElementID column), Update from Excel, then re-run - the grade climbs and the white rooms colour in.
CheckpointPlugin installed; if an export breaks, re-run Element QA/QC for a fresh sheet.
2.3
WatchClaude
Module 3 - Build & extend tools with Claude
  • Meet Claude: describe what a button should do in plain language, paste the code into a script.py, run it, fix the one error that comes back. The prompt-and-fix loop is the skill you take home.
  • Example: the wall grade is unfair - REF and generic walls have no fire rating but still lower it. Ask Claude to add an exclude-types option so they drop out, then re-run the button to see the fairer grade.
2.4
PluginExcelBrowser
Module 4 - Room brief & dashboard
  • The rooms' Brief Area starts empty. Update from Excel on D2_PA-Workshop_DATA.xlsx ▸ Space_Brief writes the target areas back (numeric, in m2, matched on RoomID).
  • Open Room Dashboard, pick Brief Area - see model area vs brief, variance and compliance by department.
  • The same button opens the full HTML scorecard straight from Revit - section diagram, metric cards, area donut, room schedule.
CheckpointD2_PA-Workshop_DATA.xlsx ▸ Space_Brief holds every target.
2.5
WatchClaudeRevit
Closing - Revit MCP: colour the facade live

A quick demo of the other AI mode: MCP, where Claude drives Revit by conversation. The instructor updates the facade mass with random offset values, then asks Claude to colour every panel by its depth in a new 3D view - the facade lights up as a heatmap, no file and no button.

Then replay the whole pipeline: Revit to Power Query to the plugin to the dashboard, and where each piece fits on your own projects.
